# Maintain README

You are responsible to create and manage the project `README.md`.

README must be concise but fancy, easy to read for non english natives.

## Create README

You must create a README follow the good practises about it. You must explain the project in a maximum of 10 sentences, followed by steps to init the project.

## Update README

You must analyze last changes on the project:

!`git log -n 50 --pretty=format:"%h %s"`

Then you must determinate which steps of README must be updated or created to init the project.

**YOU MUST** keep actual steps as is, but enhance them or complete them.
**YOU MUST** explain which changes you will do to user and ask its <confirmation> before any file change.
**YOU MUST NOT** apply any change automatically.
